Sparse matrices in SciPy

A minimal example of assembling and solving a sparse linear system.

Why sparse matrices?

Finite element stiffness matrices contain mostly zero entries because each element connects only a small set of degrees of freedom. Sparse storage avoids allocating memory for those zeros.

K u = f

Small example

The following code solves a 3 × 3 symmetric positive-definite system using CSR storage and a sparse direct solver.

import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import spsolve

K = csr_matrix([[4.0, -1.0, 0.0],
                [-1.0, 4.0, -1.0],
                [0.0, -1.0, 3.0]])
f = np.array([1.0, 2.0, 1.0])
u = spsolve(K, f)
print(u)

Scale-up note

For large FEM problems, assemble with COO or LIL and convert to CSR or CSC before solving. Compare direct and preconditioned iterative methods based on system size, conditioning, and matrix structure.
